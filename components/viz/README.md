# components/viz — 表現コンポーネント

顧客が「直感で受け取る」ための自前実装の表現をまとめる場所。数字を出さないのがここの条件。

## 既存コンポーネントとの境界

| | 置き場 | 目的 | 目盛り・凡例・数値 |
|---|---|---|---|
| 汎用チャート | `components/ui/chart.tsx` (recharts ベース) | 運営が数値を読む | あり |
| 表現 (このディレクトリ) | `components/viz/` | 顧客が直感で受け取る | なし |

運営が値を読み取るためのグラフは `components/ui` 側に置き、ここには入れない。逆に、
数字を出さない自前実装の表現・生成表現は汎用コンポーネントに混ぜず、ここへ集約する。

## 現在含まれるもの

- `wash/` — 季節のにじみ。季節と時間帯から配色を決め、流れ場と紙の粒子で面を作る。
  - `seasonal-wash.tsx` — にじみ本体
  - `reading-wash.tsx` — 読みもの系ページに敷く面
  - `journal-wash-theme.tsx` — 記事ごとのテーマ受け渡し

## 今後入る予定

- `map/` — 産地の地図。

## 分離方針

**表現は共有資産 (viz)、データは roji 固有 (lib/roji)。**

- 表現の純ロジック (色変換・流れ場・紙粒子・パレット・強調・モーション・テーマ store) は
  `lib/viz/` に置く。roji に限らず再利用できる資産として扱う。
- 産地・都道府県といった roji 固有のデータは `lib/roji/` に残す。表現側がデータを取り込む
  向きにし、`lib/viz` から `lib/roji` を参照しない。
