# components/viz — 表現 (にじみ・地図) のコンポーネント

`components/viz/` は自前実装を置く機能別ディレクトリの1つ。`components/account/` /
`components/journal/` / `components/media/` と同格で、扱う領域が「表現」であることだけが違う。
由来の分離そのものを担うディレクトリではない。

## 由来で分けるルール

> `components/ui/` はshadcn registryから入れたものだけ。自前で書いたものは絶対に置かない。
> 置き場は機能名のディレクトリ (`components/<機能>/`)。

由来を分ける規約はこの1行だけ。`components/viz/` はその「自前側」の中の一区画にすぎない。

## 現在含まれるもの

- `wash/` — 季節のにじみ。季節と時間帯から配色を決め、流れ場と紙の粒子で面を作る。
  - `seasonal-wash.tsx` — にじみ本体
  - `reading-wash.tsx` — 読みもの系ページに敷く面
  - `journal-wash-theme.tsx` — 記事ごとのテーマ受け渡し

## 今後入る予定

- `map/` — 産地の地図。

## 表現ロジックの置き場

- 表現の純ロジック (色変換・流れ場・紙粒子・パレット・強調・モーション・テーマstore) は
  `lib/viz/` に置く。特定ページに限らず再利用できる資産として扱う。
- `lib/viz/` は個別機能のデータモジュールを参照しない。データを取り込む向きは表現側からにする。
