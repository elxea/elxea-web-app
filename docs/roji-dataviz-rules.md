# rojiデータ表現の恒久ルール

rojiのデータ表現 (味の四象限 / 香りの場 / 土地を読む / 一覧のテロワール地図、
および今後のマイページ系の図) すべてに適用する非交渉のルール。

**出典**: Setaka指摘4回・2026-08-17確定。
4回とも同じ指摘 (比較対象が同カテゴリーに絞られていない) の差し戻しであり、
実装のたびに口頭で伝え直す運用が破綻したためリポジトリ側に固定した。

---

## ルール1 — 比較対象は「同じカテゴリー」だけ

いま見ているお茶と **同じカテゴリーの銘柄としか比べない**。

- 緑茶の頁を見ている人には、他の緑茶だけを出す
- 紅茶の頁なら、他の紅茶だけを出す
- カテゴリーをまたいだ比較は、どんな見せ方 (薄く出す・小さく出す) であっても行わない

適用先は単品詳細のフレーバーマップ・香りの場に限らず、**今後追加する
マイページ系の図にも同じく適用する**。

## ルール2 — 図の色はお茶のカテゴリーを表す

色が意味するのは製法でも品種でも産地でもなく、**カテゴリー**である。

ルール1と合わせると次が導かれる:

> 1枚のフレーバーマップ (香りの場) に載る点は、**必ず全て同色**になる。

図の中に2色以上のカテゴリー色が出ていたら、それはルール1の違反が
目に見えている状態であり、色の設定ミスではなく **載せる対象の誤り**である。

複数カテゴリーが同時に出てよいのは **お茶リストのテロワール地図だけ**。
あれは「いま表示中のメニュー群がどこの土地のものか」を示す図で、特定の1銘柄の
比較図ではない。そこでは色 = カテゴリーがそのまま凡例として読める
(カテゴリーで絞り込めば、当然そこも単色になる)。

## 実装上の固定点

| 何を | どこ |
|---|---|
| カテゴリーの判定と色 (唯一の入口) | `lib/roji/tea-category.ts` |
| 味の四象限の絞り込み | `lib/roji/tea-flavor.ts` の `flavorMatrixFor` |
| 香りの場の絞り込み | `lib/roji/tea-aroma.ts` の `aromaFieldFor` |
| ルールを固定するテスト | `__tests__/roji-dataviz-category-rule.test.ts` |

守るべき実装上の作法:

1. **絞り込みはデータ層で行う。** 描画側に全件を渡して「薄く描く」で済ませない。
   薄く描く実装は、ルール違反が図の上に残ったままになる。
   `flavorMatrixFor` / `aromaFieldFor` が返す集合は常に単一カテゴリーである。
2. **色は描画側が決めない。** `components/viz/**` は `TEA_CATEGORY_COLOR` から
   `data.category` の1色だけを引く。系統・製法で色を変える分岐を持たない。
3. **凡例は1行だけ。** 色の出し分けが無いことを凡例でも示す。
   4系統の色凡例が復活したら、それは2の違反である。
4. **カテゴリー不明でも全件と並べない。** 判定できないときは
   `DEFAULT_TEA_CATEGORY` に寄せる。「不明だから全部見せる」は最も重い違反。

## カテゴリーの粒度 (変えたくなったときはここだけ)

現在の粒度は **六大茶類** (緑茶 / 白茶 / 黄茶 / 青茶 / 紅茶 / 黒茶)。

根拠はrojiのマスタ採番そのもので、銘柄番号5桁の **先頭1桁が六大茶類**に
なっている (`lib/roji/tea-origins.ts` の対応表に `1xxxx = 緑茶` /
`4xxxx = 青茶` / `5xxxx = 紅茶` の註がある)。新しい分類を発明してはいない。

Sanityの `teaMenu.category` は自由記述 (`sencha` / `煎茶` / `gyokuro` …) で
六大茶類より細かいため、`normalizeTeaCategory` が六大茶類へ畳んでいる
(煎茶 も 玉露 も ほうじ茶 も緑茶なので同じ図に載る)。

粒度を「煎茶は煎茶とだけ比べる」まで細かくしたくなった場合、
変更するのは `lib/roji/tea-category.ts` の `TeaCategory` と畳み方だけでよい。
図の側・ページの側には手を入れない。

## 数値を出さない原則 (既存・再掲)

rojiの図には数値を出さない。**唯一の例外が標高** (DEMの実測値) で、
「土地を読む」の地形図レンズの計曲線と、茶園カードの標高だけがそれに当たる。
軸の目盛り・スコア・件数・パーセントは図の中に置かない。
