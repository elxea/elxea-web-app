### C8-1R (QA指摘修正) で追加した注

24. **PCカテゴリ見出しの間隔12を一度失って戻した (実装上の罠)** — SPで見出しを落とす手として
    Tailwindの `sr-only lg:not-sr-only` をh2に直接当てたところ、**`not-sr-only` が
    `margin: 0` を含むためPCの キッカー→見出し12pxが0になる**回帰が出た (再実測で検出)。
    可視化の切替はh2の内側spanに持たせ、h2の上マージンは `mt-0 lg:mt-3` で素直に
    ブレークポイント切替する形に直した。PC 12px / SP 0pxを再実測で確認済み。
25. **SP Hero内側3段は24 → 16** — Figma SP `8109:46623` の子の実測 (46624 h35底67 →
    46625 y83 / 46625底111 → 46626 y127 / 46626底177 → 46627 y193) がいずれも16。
    PC `8109:46560` 側は24のままなので `mt-4 lg:mt-6` で切り替えた。
26. **SP一報リストの節高198 → 217 (Δ19)** — 行ピッチは44で一致するが、節高は
    キッカーの行高 (Figma 18 / 実装21 = CJK再束縛・注8) と、キッカー→1行目に入れた16
    (注10) の分だけ増える。18→21で +3、Figma 0→実装16で +16 = Δ19で説明がつく。
27. **SP茶 (EC) は キッカーを出さない** — Figma SP `8109:46644` の子は見出し「茶葉」
    (46645 y64 h38) と商品カード2枚だけで、PCの "TEA LEAVES" (46598) が無い。装飾の英字
    キッカーなのでSPではDOMごと落とし (`display:none`)、見出しは残す。見出しがheadの
    先頭に来るため、キッカーとの間隔12もSPでは0にした。
28. **SP茶 (EC) の節高881.33 → 896.86 (Δ15.5)** — 差分は商品カード側の高さ
    (Figma 325.67 / 実装は写真3:2 + 3行のテキストで約341) に由来し、本節のhead構成では
    なく `ProductCard` (C4-2レーン) の寸法差。headをFigmaどおりにした結果、初版の構成
    (キッカー21 + 間隔12を余分に持っていた) よりFigmaに近づいている。
29. **SPカテゴリは32px見出しを出さない** — Figma SP `8109:46629` はキッカー "CATEGORIES"
    のみ。ただし節の名前づけ (見出し) をa11yツリー / SEOから失わせたくないので、h2は
    `sr-only` でDOMに残す (SPの実測高さ0 / 上マージン0でレイアウトには効かない)。
30. **SPカテゴリのタイル上限は3 (PC 6)** — Figma SPは1列x 3段。実装はShopify
    コレクションを最大6件取り、4枚目以降を `hidden lg:flex` でPC限定にする。
    **実データが1件なら1枚しか出ない** (Vercel Previewの実測どおり)。「データが無い節・枠は
    出さない」方針と同じで、足りない分を空枠で埋めることはしない。
31. **SPカテゴリの節高1037 → 1042.59 (Δ5.6)** — キッカーの行高 (18→21 = +3) と、タイル
    高さ (Figma 284 / 実装284.54 = 写真247.34 + 12 + ラベル25.2) の +0.54 x 3 = +1.6、
    残りは行gapの丸めで説明がつく。いずれもトークン由来で本節固有の差ではない。
32. **章切りのキッカー→見出し20 → 24** — FigmaはPC (`8109:46593` y163.5 h17 →
    `8109:46594` y204.5) / SP (`8109:46641` y126 h17 → `8109:46642` y167) ともに24。
    実装は `mt-5` (20) で組んでいたので `mt-6` (24) に直した。PC / SP共通の是正。
